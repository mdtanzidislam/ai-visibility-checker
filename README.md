## 🎯 Purpose & Capabilities

Modern generative search engines (including ChatGPT Search, Perplexity AI, Claude, and Google AI Overviews) utilize Retrieval-Augmented Generation (RAG) and vector embedding pipelines to synthesize answers. Traditional search crawlers are being augmented or replaced by AI agent bots (`GPTBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`).

The **AI Visibility Checker** evaluates:
1. **Agent Accessibility:** Verifies that Cloudflare WAF or anti-bot shields do not inadvertently block generative crawlers.
2. **llms.txt Compliance:** Inspects machine-readable markdown discovery endpoints (`/llms.txt` and `/.well-known/ai-plugin.json`).
3. **Semantic Entity Grounding:** Validates JSON-LD Knowledge Graph architecture and Schema.org disambiguation.
4. **Passage Citability:** Evaluates information gain, direct-answer density, and statistical verifiability.
